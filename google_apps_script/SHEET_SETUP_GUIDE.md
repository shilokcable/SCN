# SCN [Shilok Cable Network] - Google Sheets & Apps Script সেটআপ গাইড

এই সিস্টেমটি সম্পূর্ণ **বিনামূল্যে (Free Hosting)** গুগল শিট ও গুগল অ্যাপস স্ক্রিপ্ট (Google Apps Script) দিয়ে চালানো যাবে। কোনো ডোমেন বা পেইড হোস্টিং লাগবে না।

---

## ধাপ ১: নতুন গুগল স্প্রেডশিট তৈরি
1. আপনার ব্রাউজারে [Google Sheets](https://sheets.new) ওপেন করুন।
2. শিটের নাম দিন: **"SCN Shilok Cable Network Database"**।

---

## ধাপ ২: Apps Script এডিটর ওপেন করা
1. গুগল শিটের উপরের মেনুবার থেকে **Extensions (এক্সটেনশন)** -> **Apps Script**-এ ক্লিক করুন।
2. Apps Script এডিটর উইন্ডো ওপেন হবে।

---

## ধাপ ৩: কোড পেস্ট করা

### ১. `Code.gs` ফাইল:
- বাম পাশের ফাইলে `Code.gs`-এ থাকা আগের কোড মুছে দিন।
- `/google_apps_script/Code.gs` ফাইলের সমস্ত কোড কপি করে পেস্ট করুন।
- উপরের **Save (আইকন)**-এ ক্লিক করুন।

### ২. `Index.html` ফাইল যোগ করা:
- বাম পাশে **Files**-এর পাশে **+** বাটনে ক্লিক করুন -> **HTML** সিলেক্ট করুন।
- ফাইলের নাম দিন: **`Index`** (বা `Index.html`)।
- `/google_apps_script/Index.html` ফাইলের সমস্ত কোড কপি করে সেখানে পেস্ট করুন।
- সেভ (Save) করুন।

---

## ধাপ ৪: ১-ক্লিকে ডেটাবেজ ইনিশিয়ালাইজ (Auto Setup)
- Apps Script এডিটরের উপরে ফাংশন সিলেক্ট ড্রপডাউন থেকে **`initDatabase`** নির্বাচন করুন।
- **Run (চালান)** বাটনে ক্লিক করুন।
- গুগল প্রথমবার "Authorization Required" চাইবে -> **Review permissions** -> আপনার জিমেইল অ্যাকাউন্ট সিলেক্ট করুন -> **Advanced** -> **Go to SCN Shilok Cable Network (unsafe)** -> **Allow** দিন।
- মাত্র ৫ সেকেন্ডে আপনার গুগল শিটে স্বয়ংক্রিয়ভাবে ৪টি ট্যাব তৈরি হয়ে যাবে:
  1. **Clients** (সকল ক্লায়েন্ট ও রাউটার তথ্য)
  2. **Collections** (বিল জমার ইতিহাস)
  3. **EditRequests** (কালেক্টর এডিট রিকোয়েস্ট)
  4. **Settings** (বিলের মাস ও কোম্পানির তথ্য)

---

## ধাপ ৫: ওয়েব অ্যাপ হিসেবে পাবলিশ (Deploy as Web App)
1. Apps Script এডিটরের উপরে ডানে **Deploy** -> **New deployment**-এ ক্লিক করুন।
2. গিয়ার আইকন (Select type) থেকে **Web app** সিলেক্ট করুন।
3. সেটিংস দিন:
   - **Description:** `SCN Billing Web App v1`
   - **Execute as:** `Me (আপনার ইমেইল)`
   - **Who has access:** `Anyone (যেকোনো ব্যক্তি)`
4. **Deploy** বাটনে ক্লিক করুন।
5. আপনি একটি **Web App URL** পাবেন (যেমন: `https://script.google.com/macros/s/AKfy.../exec`)।

---

## ধাপ ৬: ব্যবহার শুরু
- এই লিঙ্কটি আপনার মোবাইল, কম্পিউটার বা কালেক্টরদের হোয়াটসঅ্যাপে পাঠিয়ে দিন।
- ২ জন কালেক্টর যেকোনো মোবাইল থেকে দ্রুত লগইন করে ক্লায়েন্ট সিলেক্ট করে বিল জমা করতে পারবেন।
- প্রতিবার বিল জমা হলে তা মুহূর্তের মধ্যে গুগল শিটের **Collections** ট্যাবে যুক্ত হবে এবং ক্লায়েন্টের ব্যালেন্স আপডেট হয়ে যাবে!
- ক্লায়েন্ট তার PPPoE বা আইডি দিয়ে লগইন করে সরাসরি তার রাউটার ম্যানেজমেন্ট আইপি ও পাসওয়ার্ড দেখতে পারবেন।
